# 家庭囤货盘点（单机 PWA）

保质期预警 · 补货清单 · 定期盘点 · 分类/位置管理 · CSV/JSON 导入导出 · 家人同步码。

## v3.0 新增
- **历史记录**：每次加减、用掉、过期处理、入库、盘点、改数量都会记下谁、何时、变化多少；「统计」页看月度/年度用掉、买入、过期浪费、分类占比、用得最多排行和明细，可导出 CSV
- **消耗推算**：按最近 90 天记录算日均用量、预计用完日期；首页「N 天内会用完」+ 建议购买量（够用到下次采购并补回水位）
- **自动安全水位**：水位 ≈ 日均用量 × 安全天数，按记录多少逐步从初值靠拢建议值；手动改过的物品锁定不动
- **输入**：名称不再弹下拉；按名称自动推荐单位/分类/初始水位（先参考家里已有物品，再查常见词库）；单位一键选
- **入库确认**：勾选的物品入库前可改数量、填新批次到期日
- 设置里可调「采购周期」「安全天数」；分类加 ✏️ 编辑入口；升级时自动保留升级前数据快照
纯前端，无服务器、无账号；**数据保存在每台手机自己的浏览器 / 桌面 App 里**，本仓库只有程序代码。

## 家庭自动同步（v2.1 起，可选）
用一个**另外的 GitHub 私有仓库**当家庭云盘（文件 `home-stock-data.json`）：
- 一人在 App「设置 → 家庭自动同步 → 我来创建」填仓库和细粒度令牌（只给该仓库 Contents 读写），再「邀请家人」
- 家人「我有邀请码」粘贴一次即可，无需注册
- 打开 App、切回前台、开着时每 30 秒自动拉取；本机改动约 3 秒后自动上传
- 按字段三方合并：不同人改不同字段都保留，同时增减数量会累加；删除会同步
- 手动同步码同样改为合并，不再覆盖

## 手机安装
- **iPhone**：用 Safari 打开网址 → 分享按钮 → 添加到主屏幕 → 以后只从桌面图标打开
- **安卓**：用 Chrome/Edge/系统浏览器打开 → 右上角菜单 → 添加到主屏幕 / 安装应用
- 微信里打开时，先点右上角「···」→「在浏览器打开」

## 文件
- `index.html` 整个 App（单文件，也可直接用浏览器打开）
- `manifest.webmanifest` / `sw.js` / `icons/` 让它能添加到桌面、离线使用

## 更新
改完 `index.html` 后，把 `sw.js` 里的 `VERSION` 加一，推送即可；手机下次联网打开自动更新，数据不受影响。
